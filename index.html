使い方

このアプリについて

一級建築士製図試験の練習時間を工程ごとに計測・記録し、成長を分析するツールです。データはすべてこの端末にのみ保存され、外部には送信されません。

セッションを始める

ホーム画面の「新規セッション」のほか、上に並んだ4つのタイル（エスキス / 記述 / 作図 / フル）を押しても始められます（タイルの下に目印が付いています）。タイルから入るとそのモードが選ばれた状態になります。

① 課題名を入力（例：課題No.3 福祉施設）

② モードを選択

フル：390分フル通し

エスキスのみ：エスキスまで

作図のみ：作図・断面図のみ

記述のみ：計画の要点のみ

③ 工程セットを選ぶ

同じモードの中に工程の組み合わせを複数持てます（例：作図の「本番想定（180分）」と「作図タイムトライアル（60分）」）

設定 → 工程カスタマイズ で追加・編集できます

④ 本番の開始時刻を設定（任意）

本番が11:00開始なら 11:00 のままでOK。工程一覧に「その工程を終えているべき時刻」が出ます

空欄にすると実時刻の表示をしません

⑤ 計測開始を押す

タイマー操作

次の工程へ：現在の工程を記録して次へ進む

1つ戻す：押し間違えたとき、直前のラップを取り消して前の工程に戻る

一時停止：タイマーを止める（再開で再スタート）

完了：最終工程で「次の工程へ」が「完了」に変わります

終了：最後の工程として記録し振り返りへ

「完了」と「終了」は確認のダイアログが出ます（誤って2回押しても計測が終わらないように）。確認している間の時間は記録に加算しません。

PCキーボード：Enter = 次の工程 / Space = 一時停止 / BackSpace = 1つ戻す

工程タイマーが目標時間を超えると赤字表示

遅れ / 貯金：累計タイムの下に、目標に対して何分押しているかを表示します。工程ごとの赤字と違い、全体でどれだけ遅れているかが分かるので、どこで巻くかの判断に使えます。

本番なら 15:42：開始時刻を設定していると、経過時間を本番の実時刻に換算して表示します。あわせて残り時間と終了予定時刻も出るので、「あと何分あるか」を頭の中で計算しなくて済みます。

計測中は画面が自動で消えないようにします（対応ブラウザのみ）。

目標到達の知らせ：セッション設定で「音」か「バイブ」を選ぶと、工程の目標時間に達したときに1回知らせます。既定は「知らせない」です。作図中で画面を見ていないときに使います。

端末が対応している手段だけが選択肢に出ます。iPhone / iPad はバイブに対応していないため「音」だけになります

端末を消音（サイレント）にしていると音は鳴りません。練習を始める前に消音を解除してください（iPad で確認済み）

振り返り

各工程の実績・目標・過去平均を比較できます。

Good / Badで各工程を評価（目標との比較で自動設定）

この回の出来：セッション全体を星1〜5で評価できます（任意）。工程ごとのGood / Badとは別に、「会心の出来だった回」を後から探すための印です

メモを入力して保存するを押すと履歴に記録されます。

保存せず終了：記録せずホームへ戻ります。

分析

成長推移：累計カウンター（総セッション数 / 練習した日数 / 総練習時間）と直近6ヶ月のヒートマップ、合計タイムの折れ線

カウンターとヒートマップは常に全記録が対象です（フィルタで減りません）。ヒートマップのマスは色が濃いほどその日の練習時間が長く、押すとその日の記録が出ます

工程内訳：全工程の積み上げ棒グラフ、または工程を選んで折れ線表示

工程比較：各工程の平均・最速・最遅タイム

評価分析：工程ごとのGood率（Bad多い工程を強調表示）

モード・工程セット・課題名・星評価でフィルタ可能

工程名を変えても、同じ工程として過去の記録と繋がったまま集計します

設定

工程カスタマイズ：工程セットの追加・削除、工程名・目標時間の変更、順番の入れ替え

1つのモードに複数の工程セットを持てます。回数・ベストタイム・分析はセットごとに集計します

フルモードの既定セットは合計390分になるよう設定（保存時に確認）

テーマカラー：アクセントカラーを変更

データ管理：JSONバックアップ・CSVエクスポート・全データリセット

ホーム画面に追加して使う

アプリとして追加すると、全画面で起動してブラウザのバーが消え、誤タップで画面が飛ぶ事故を防げます。オフラインでも動作します。

iPhone / iPad：共有ボタン → 「ホーム画面に追加」

Android：メニュー → 「アプリをインストール」

PC（Chrome / Edge）：アドレスバー右のインストールアイコン

データについて

すべてのデータはこの端末のブラウザ（localStorage）にのみ保存されます。外部への送信はありません。

次の場合は記録が消えます。設定 → データ管理 → エクスポートで定期的にバックアップを取ってください。記録が10件たまるごとに、ホーム画面でもお知らせします。

・ブラウザの閲覧データ（Cookie・サイトデータ）を削除したとき

・プライベートブラウズで使ったとき

・iPhone / iPad で、ホーム画面に追加せず長期間開かなかったとき

・別の端末・別のブラウザで開いたとき（記録は共有されません）

免責

工程と目標時間は練習の目安です。試験の結果を保証するものではありません。本ツールの利用によって生じた不利益について、作者は責任を負いません（MIT License）。
